# WordSmrt

**WordSmrt** is a privacy-first, offline Android vocabulary learning application designed to help users **learn, remember, and master English vocabulary** through flashcards, bilingual definitions, quizzes, spaced repetition, and real-time progress tracking.

## ✨ Features

- 📚 **1,700+ vocabulary words** with English definitions and Bangla meanings
- 🧠 **Flashcards** with persistent learning states
- 🎯 **Vocabulary quizzes** with four-option questions
- 🔄 **Spaced repetition** and intelligent review scheduling
- 📈 **Real-time analytics** and vocabulary mastery tracking
- 🔎 **Bilingual dictionary search** — English & Bangla
- 🔊 **Pronunciation support**
- 📅 **Word of the Day**
- 🎯 **Daily vocabulary goals**
- 🔥 **Study streaks**
- ⭐ **Vocabulary mastery states** — New, Learning, Review, Difficult & Mastered
- 📊 **Progress and mastery distribution**
- 🌙 **AMOLED-friendly dark interface**
- ⚡ **Fast, lightweight, and completely offline**

## 🔐 Privacy First

WordSmrt is designed around **local-first, permission-free learning**.

> **Your vocabulary. Your progress. Your device.**

WordSmrt does **not require any permissions** to function.

| Privacy Feature | WordSmrt |
|---|---|
| 🌐 Internet access | ❌ Not required |
| 📡 Network access | ❌ None |
| 📷 Camera access | ❌ None |
| 📁 File/storage access | ❌ None |
| 📍 Location access | ❌ None |
| 🎙️ Microphone access | ❌ None |
| 👤 Account required | ❌ No |
| ☁️ Cloud sync | ❌ None |
| 📤 Personal data collection | ❌ None |
| 💾 Learning data | ✅ Stored locally |

All vocabulary progress, review history, streaks, quiz results, and
learning statistics remain **locally on the device**.

## 🧠 Learning System

WordSmrt separates vocabulary data from personal learning progress.

Each word can move through:

`NEW → LEARNING → REVIEW → MASTERED`

Words marked as difficult are also tracked separately, while the
spaced-repetition system determines when mastered words should return
for review.
